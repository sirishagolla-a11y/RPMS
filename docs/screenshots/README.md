# RLW Application Screenshots & Interface Visuals

The RLW system features a high-contrast dark theme with dynamic status badges, thermal receipt previews, and visual trend charts.

## Key Screens Showcase

1. **Dashboard Overview**
   * Real-time metrics for currently parked vehicles, today's entries/exits, total revenue, active passes, and 5-day expiry warnings.

2. **Vehicle Entry & Check-In**
   * Rapid registration modal supporting casual vehicles and instant zero-tariff monthly pass recognition.

3. **Vehicle Exit Checkout & Receipt Generation**
   * Duration-based tariff calculator with Cash/UPI options and a thermal ticket printer view.

4. **Shift Management & Cash Handover**
   * Active operator duty tracking with automatic revenue collection calculation upon shift closure.

5. **Reports & Parking Analytics**
   * Period filters (Today, 7 Days, Month, Custom) with occupancy progress gauges, revenue splits, and daily trend bar graphs.

6. **Monthly Pass Management & WhatsApp Reminders**
   * Customer subscription lifecycle management and Meta WhatsApp Cloud API reminder controls.
